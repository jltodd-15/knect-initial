# D8. Settings, Logout & Account Deletion

STATUS: UNWRITTEN — do not build

**Purpose:** logout from the Profile tab, settings, and account deletion — an App Store requirement for any app with accounts.

**Already known:** deleting a user leaves references in every friend's `Friends`, every chat's `participants`, and every event's `shared_with`/`rsvps`. Every screen already has a "Deleted user" fallback (Q3). Provider unlinking for Google/Apple belongs here (`*1.3`).

**Open questions:** cleanup strategy — cascade via Function, tombstone the user doc, or soft-delete (a schema decision).

**Depends on:** 1.2, D2.
