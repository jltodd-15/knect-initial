# D5. User Status

STATUS: UNWRITTEN — do not build

**Purpose:** a light way to mark yourself available or unavailable to hang out. Ship it and learn whether anyone uses it — minimal surface, no notifications, no status feed (O8).

**Already known:** fields `Users.current_status`, `status_visibility`, `status_expires_at`; not written at signup (`*2.2`). 0.1 restores `UserStatus.timestamp` as-is; D5 turns it into `status_expires_at` with a real TTL. Lives on the Circle tab. `*3.2` allowlists all three without constraining values.

**Open questions:** the `status_visibility` value set (Q11); the name collision with `Friends.status`; expiry behavior.

**Depends on:** `*2.2`, `*3.2`.
