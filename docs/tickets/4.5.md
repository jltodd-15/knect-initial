The redesign changed the appendix the next day: dark text on green buttons, more color tokens, event colors with a solid shade, a new type scale in Manrope, and Lucide icons. This ticket brings the code up to the appendix. **It updates values where they are already used. It does not restyle any screen to match a board;** that belongs to each screen's own ticket.

**1 - Goals**
The app's colors, type and icons come from Appendix A as it stands on 2026-10-09, in light and dark.

**2 - Architecture & Technical Details**
- **Data model changes:** None.
- **Source of values:** Appendix A and `docs/design/tokens.json`, which agree. `theme/tokens.ts` is written by hand to match; a test compares it to `tokens.json` so the two cannot drift.
- **Colors.** Add `danger-text`, `danger-border`, the four `warning` tokens, `backdrop`, `tab-bar`, `divider`, `text-strong`, the three `busy-` tokens, and `on-danger` (`#ffffff`, ruled 2026-10-09). Change `on-primary` to `#052e22` and dark `placeholder` to `#71717a`. 4.2's three extras (`shadow`, `scrim`, `onPrimaryMuted`) stay.
- **The `onPrimary` audit.** Until now `onPrimary` meant "white on any colored block". It now means "text on a `primary` fill" and is dark. Every existing use is checked against what it sits on:
  - on a `primary` fill → stays `onPrimary`;
  - on a `danger` fill → `onDanger`;
  - on a photo, an event color, a dark toast, or a switch thumb → a new code-only token, `onColor` (`#ffffff` in both modes), so these keep looking as they do today. Like 4.2's three extras it is not in Appendix A.
- **Event colors.** `eventColors` becomes the six entries of A.2.1, each with `base`, `solid`, `textOnBase`, `textOnSolid` and `proposedFill`. The stored value on an event is still the base hex. How events are drawn does not change here (18.1).
- **Type scale.** A.3 as written: twelve styles, each carrying `fontFamily: 'Manrope'` and its letter spacing. No weight above 800.
- **Radius and sizes.** Add `radius.event` and the fixed sizes of A.5.
- **Fonts.** One family name, `Manrope`, with weights 400–800 chosen by `fontWeight`, on both platforms. iOS: the five files in the app bundle and in `UIAppFonts`. Android: the five files as a font resource family, registered at startup.
- **Icons.** `lucide-react-native`, `strokeWidth` 2.4, sizes 24 / 18 / 16. Icon names from A.6 and `tokens.json`.

**3 - UI & Layout**
No layout changes. What will look different:
- Text and icons on green buttons and green selected states turn from white to dark green.
- All text is set in Manrope; sizes follow the new scale where a screen already used a type token.
- Tab bar icons, chevrons, the star and other matched icons are Lucide's.
- Dark-mode placeholder text is lighter.

**4 - Security and Scope**
- **In scope:** the three parts above; updating `CLAUDE.md`'s styling lines, the README and the roadmaps.
- **Out of scope:** restyling any screen; the Planner's event rendering (18.1); `components/ChatEventWidget.tsx` (dead, per `CLAUDE.md`); the crash screen's theme.
- **Files allowlist:** `theme/*`, every file in `components/` and `App.tsx` (values, font family and icons only), `package.json` and `package-lock.json` (one dependency), `ios/Knect/Info.plist`, `ios/Knect.xcodeproj/project.pbxproj`, `ios/Knect/Fonts/*`, `android/app/src/main/res/font/*`, `android/app/src/main/java/**/MainApplication.kt`, `jest.setup.js` only if the new icon library needs a stand-in.
- **Security rules changes:** No changes needed.
