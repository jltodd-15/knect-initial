# *13.3. User Generated Content

STATUS: UNWRITTEN — deferred — do not build. **Cannot stay deferred through launch** — it owns content reporting, which gates App Review.

**Purpose:** users create activities others see, and see likes/views on their own; plus the content-reporting mechanism (Apple Guideline 1.2).

**Already known:** UGC activities use `source: "user_generated"` and `creator_id`; `*3.2`'s rules already gate on them. `is_active` and `updated_at` are added here (O7, Q12) and retrofitted into 11's and 13.1's queries and indexes. Reporting scope must cover user-created activities, chat messages, and profile fields; each surface adds its own entry point. UGC photos need Storage (D9). Starred: App Review gate.

**Open questions:** moderation model (publish instantly?); takedown path; free-text vs fixed tags; editing/deleting an activity referenced by an Event or message; whether reporting needs a server-side block record (would reopen the blocking ruling).

**Depends on:** 8, 6, D9.
