# 8\. Define Activity Schema

### `Define Activity Schema` 

**`1. User Story`**

* `As a user, I want to have the ability to easily filter and see data, in a uniform way, about all the activities on the discover tab.`

**`2. The Architecture & Technical Details`**

* **`Target Database:`** `Collection: Activities, Document: Unique Activity ID`  
* **`The Data Payload:`**  
  * `name (String)`  
  * `location (Map/GeoPoint)`  
  * `geohash (String)`  
  * `cost (String: e.g., "Free", "$", "$$")`  
  * `source (String: e.g., "api_yelp", "manual_diy")`  
  * `description (String)`  
  * `tags (Array of Strings: e.g., "outdoors", "music")`  
  * `pictures (Array of Strings)`  
  * `click_count (Integer)`  
  * `likes (integer)`  
  * `is_location_based (Boolean)`  
  * `created_at (Timestamp)`  
* **`Location Filtering:`** `The frontend must use a Firebase Geohash Query to only pull and display activities within a 25-mile radius of the user's saved geohash.`  
* **`Engagement Tracking:`** `Handled via a server-side Firebase Cloud Function. When a user likes or taps on an activity in the Discover tab, the app fires a request to the Cloud Function to add to the click_count/likes counter, up by 1.`

**`3. UI & Layout Requirements`**

* **`The View State (The Activity Card):`** `The activity card should have a picture at the top, with the bottom 2/5ths to have a background (color dependent on dark mode). The Name should be the title, with the description smaller beneath it. If the description is too long it should add an ellipses to where it is cut off. Off to the side add the String of the Cost. There should also be a heart icon you can like (turning red when you do) on the bottom right hand corner.`  
  `One key thing is I would like the height to be just short enough you can see the next activity under it, hopefully piquing interest.`   
* **`The View State (The Activity’s page):`** `When they click on the card it should open a page that is similar to the card. It should take the whole screen, expanding the space the picture takes. It should also add the tags for each activity and a button that leads to the create an event page with the name and location of the activity already filled with the info from that activity.`  
* **`The Image Carousel:`** `They should be able to swipe through the images if there are multiple. It shouldn’t automatically rotate.`  
* **`The Empty/Error State:`** `If there is an error, lack of cards or wifi, put a message that says “Sorry, We couldn’t load anything right now” Along with a circle and “!” in the middle of it.`

**`4. Acceptance Criteria`**

- [ ] `You can write a dummy activity (or one from Preston’s google sheet) that fills every string outlined above. The pictures must also show up properly.`  
- [ ] `There are no empty fields.`  
- [ ] `If there is missing data, the event should not be able to be shown.`
